# Project notes

## What this is
- Luminary: an AI learning companion built on the Claude API (Node server + web front end).
- innings.html: a small standalone tool (Daily Innings) with tasks, a focus timer and a streak.

## How to run
- Install: npm install
- Start: npm start
- Dev (auto-restart): npm run dev
- Demo without API key: npm run demo
- Test: npm test
- Needs Node 20 or newer

## Folders
- public/ = front end
- server/ = back end
- data/ = local data
- test/ = tests
- .github/ = CI setup
